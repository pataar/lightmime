Your Hue lights, following your screen.

lightmime syncs Philips Hue lights with your screen on Linux. The left of the picture goes to the lights left of your monitor or TV, the top to the lights above it, streamed over the Hue Entertainment API with low latency, the way Hue Sync does on other systems.

Install Quickstart Source on GitHub

A tiny footprint

One native Rust binary: no interpreter, browser engine or web server. It drops frames above the sync rate and shrinks the rest before looking at them, so it keeps out of the way of whatever is on your screen.

Ambient light for the Linux desktop

One small Rust binary that pairs with your bridge, captures the screen and keeps the lights in step.

Made for Wayland

Capture goes through the desktop's screen-cast portal and PipeWire, on KDE Plasma, GNOME and wlroots compositors such as Sway and Hyprland. X11 works too. You pick the screen once.

A window and a tray icon

Pair with the bridge, choose an entertainment area and press Start. Tune brightness, smoothing and saturation while it runs; the tray starts and stops syncing.

Updates itself

Install it from lightmime's own Flatpak repository and new releases arrive through flatpak update or your software centre.

Headless if you like

lightmime run syncs without a window, for example as a systemd user service on a media PC.

Home Assistant, optionally

Turn on MQTT and lightmime shows up as a device with a sync switch, a status sensor and sliders for dashboards and automations.

Private and open source

It talks to your bridge on the local network and nothing else unless you enable MQTT. Dual-licensed under MIT or Apache-2.0.

How it works

Three stages, run for every frame, from the picture on your screen to the lights around it.

  1. Step 1

    Capture

    The desktop's screen-cast portal asks once which screen to share and hands lightmime a PipeWire stream of it. No extra permissions, also in the Flatpak.

    xdg-desktop-portalPipeWire64 × 36 RGB
  2. Step 2

    Map

    Every light in the entertainment area takes the average colour of the screen around its position, then gets your saturation, smoothing and brightness.

    linear lightsaturationsmoothing
  3. Step 3

    Stream

    The colours go to the bridge over the Hue Entertainment API, the same encrypted stream Hue Sync uses, so the lights follow with low latency.

    DTLS 1.2UDP 2100HueStream v2

Install

Releases are built for x86_64 and aarch64. Then follow the Quickstart: pair, choose an area, press Start.

Recommended. lightmime has its own Flatpak repository, so new releases arrive through flatpak update or your software centre.

$ flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
$ flatpak remote-add --user --if-not-exists lightmime https://lightmime.pataar.nl/flatpak/lightmime.flatpakrepo
$ flatpak install --user lightmime io.github.pataar.lightmime

A tarball from the latest release. It uses your system's GStreamer and OpenSSL; Install lists the packages per distribution and how to add the launcher entry.

$ curl -LO https://github.com/pataar/lightmime/releases/latest/download/lightmime-x86_64-unknown-linux-gnu.tar.xz
$ tar -xJf lightmime-x86_64-unknown-linux-gnu.tar.xz
$ install -Dm755 lightmime-x86_64-unknown-linux-gnu/lightmime ~/.local/bin/lightmime

From crates.io. Needs Rust and the development files of GStreamer, OpenSSL and xkbcommon; Install lists them per distribution.

$ cargo install --locked lightmime
$ cargo install --locked lightmime --no-default-features  # headless, without window and tray

From a checkout, with the same build dependencies as Cargo.

$ git clone https://github.com/pataar/lightmime
$ cd lightmime
$ cargo install --locked --path crates/lightmime

What you need

  • A Philips Hue bridge (the square, second-generation one) with an entertainment area set up in the Hue app.
  • A Linux desktop with PipeWire and xdg-desktop-portal with a screen-casting backend. Most current desktops have both.
